# Rajeev K R — Portfolio

Static portfolio site designed for GitHub Pages.

## Before publishing

1. Replace `YOUR_USERNAME` in `index.html` with your GitHub username.
2. Replace `YOUR_LINKEDIN` with your LinkedIn profile slug.
3. Replace the placeholder GitHub project links with the actual repository URLs.
4. Keep `assets/resume.pdf` if you want the CV button to work.

## Publish with GitHub Pages

Create a repository named `<your-username>.github.io`, upload the contents of this folder, and enable GitHub Pages from the repository's Pages settings using the `main` branch and root folder.
